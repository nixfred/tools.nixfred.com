# Tool PRD — Permission Planner

## User outcome

Decide what an AI system may read, write, send, spend, approve, or delete.

## Workflow

Add resources and actions; assign risk, reversibility, data sensitivity, and autonomy level; define approval and escalation rules.

## Outputs

Permission matrix, risky combinations, least-privilege suggestions, approval boundaries, and audit requirements.

## Boundaries

The tool provides design guidance, not legal or security certification.

## Acceptance criteria

- Destructive and externally visible actions cannot be marked low-risk without a warning.
- Wildcard access is clearly surfaced.
- Matrix exports in human-readable and structured forms.
- Includes a realistic email-and-calendar agent sample.
