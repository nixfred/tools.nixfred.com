# Tool PRD — Signal Tester

## User outcome

Evaluate whether an AI-generated claim is supported, specific, attributable, and decision-relevant.

## Workflow

Paste a claim and its cited evidence; mark source type and date; inspect a structured quality assessment.

## Outputs

Support map, unsupported leaps, ambiguity, source gaps, freshness risk, and a rewritten evidence-calibrated claim.

## Boundaries

This is not a general truth machine or live fact-checker. It evaluates supplied evidence unless a later PRD explicitly adds retrieval.

## Acceptance criteria

- Claim fragments map to evidence passages.
- Fact, inference, prediction, and opinion are distinguished.
- Missing evidence reduces confidence visibly.
- Pasted content remains local.
